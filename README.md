# 一箭又一箭

一个使用 Python + Pygame 开发的箭头点击解谜小游戏。

## 1. 项目简介

玩家需要按照合适的顺序点击棋盘中的箭头。

箭头有四个方向：

- 上
- 下
- 左
- 右

点击箭头后，程序检查箭头前进方向到棋盘边界之间是否存在其他箭头。

- 没有阻挡：箭头飞出棋盘并消失。
- 存在阻挡：箭头不能消失，并消耗一次失误机会，同时产生碰撞反馈变红。
- 清空当前关卡：通关并进入下一关。
- 失误次数归零：本关失败，可以重新开始。

游戏共设计 3 个固定关卡。

## 2. 开发环境

- Windows
- Python 3.10+
- Pygame

## 3. 安装

打开终端，在项目目录执行：

```bash
python -m pip install pygame
```

## 4. 运行

```bash
python main.py
```

## 5. 游戏操作

- 鼠标左键：点击箭头
- 重新开始：恢复当前关卡的初始状态
- 通关后：点击“进入下一关”
- 失败后：点击“重新开始”

## 6. 核心实现

棋盘采用二维网格表示。

每个箭头使用：

```text
(行, 列): 方向
```

例如：

```python
(2, 3): "R"
```

表示第 2 行第 3 列存在一个向右箭头。

路径检测根据箭头方向逐格检查：

```text
向上：检查同一列上方
向下：检查同一列下方
向左：检查同一行左方
向右：检查同一行右方
```
